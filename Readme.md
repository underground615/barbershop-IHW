# ИДЗ №2 — «Задача о парикмахере»

Консольная многопоточная программа на C17 с pthread, мьютексом и семафорами. Каждый парикмахер и каждый посетитель работают в отдельном потоке.

## Сборка и запуск в Linux

```bash
cmake -S . -B build
cmake --build build
./build/main --barbers 2 --chairs 3 --customers 20 --strategy fifo --seed 42
```

Без CMake:

```bash
gcc -std=c17 -D_POSIX_C_SOURCE=200809L -Wall -Wextra -pthread src/main.c src/shop.c src/queue.c src/simulation.c -o main
./main
```

Параметры: `--barbers`, `--chairs`, `--customers`, `--arrival-min`, `--arrival-max`, `--haircut-min`, `--haircut-max`, `--closing`, `--strategy fifo|lifo|random`, `--seed`, `--log`.

Время задаётся в миллисекундах. Задержки теперь реальные: стрижка на 2000 ms занимает примерно две секунды. При отсутствии мест посетитель уходит. Приём заканчивается по числу посетителей или времени закрытия, затем обслуживаются все принятые клиенты.

Очередь и общие данные защищены мьютексом. Семафоры будят парикмахеров и позволяют клиенту дождаться стрижки, а парикмахеру — освобождения кресла. Во время стрижки мьютекс не удерживается.

События и итоговая статистика выводятся в консоль и журнал (`simulation.log` по умолчанию). `--seed` задаёт начальное состояние генератора, но порядок выполнения потоков и точное время могут различаться между запусками.

```bash
ctest --test-dir build --output-on-failure
```

Обработчика сигналов нет: Ctrl+C завершает процесс без гарантии итоговой статистики.
