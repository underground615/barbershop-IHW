# ИДЗ №1 — «Задача о парикмахере»

Консольное приложение на **C17**, реализующее последовательную событийную симуляцию работы парикмахерской без использования потоков.

## Возможности

- Несколько парикмахеров и ограниченная очередь ожидания.
- Стратегии очереди: FIFO, LIFO, RANDOM.
- Случайное время прихода посетителей и длительность стрижек.
- Настройка параметров через аргументы командной строки.
- Завершение моделирования, обработка сигналов и сохранение журнала.
- Статистика обслуживания, ожидания и загрузки парикмахеров.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
./build/main
```

## Параметры запуска

```bash
./build/main --barbers 2 --chairs 3 --customers 20 --strategy fifo --seed 42
```

`--barbers` — число парикмахеров, `--chairs` — места ожидания, `--customers` — количество посетителей, `--strategy` — стратегия очереди, `--seed` — зерно генератора случайных чисел.

Временные параметры задаются в миллисекундах.

## Принцип работы

Программа последовательно обрабатывает ближайшее событие: приход посетителя или завершение стрижки. Если все парикмахеры заняты, посетитель ожидает в очереди либо уходит при отсутствии мест.

## Результаты

После завершения выводятся статистика обслуживания, среднее время ожидания и загрузка парикмахеров. События сохраняются в файл журнала.
